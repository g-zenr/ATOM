## Colophon

ATOM is a personal workspace app — Notes, Tasks (GitHub Issues–style workflow), and Time tracking — built as an npm-workspaces monorepo on Next.js 16 (App Router, Turbopack, Cache Components) with Prisma and Neon Postgres, deployed to Google Cloud Run. Automation surface: REST API for n8n and a Discord bot.

This book was written against the source code itself — every file, schema, and endpoint referenced here exists in the repository as described.

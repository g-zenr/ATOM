# Principles

> Chapter 1 — Overview · [Contents](../table-of-contents.md)

1. **Personal first.** Single user initially; no corporate project-management baggage.
2. **Fast capture.** Adding a note, task, or clock-in takes seconds, with or without JavaScript.
3. **Familiar workflow.** Task statuses mirror GitHub Issues: **Todo → In Progress → Done**.
4. **One source of truth.** Validation, types, and formatting rules live once (`packages/shared`) and are reused everywhere.
5. **Standards over cleverness.** Official Next.js patterns (App Router, Server Components, Server Actions, Zod, DAL) — see [chapter 11](../standards/README.md).

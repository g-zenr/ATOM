# Atom info

> Chapter 1 — Overview · [Contents](../table-of-contents.md)

ATOM is a **personal workspace**: one place for the three things that make up a day's work.

| Feature           | Purpose                                        | Status                                                       |
| ----------------- | ---------------------------------------------- | ------------------------------------------------------------ |
| **Notes**         | Capture and revisit information                | ✅ Create, view, delete, search, paginate                    |
| **Tasks**         | Track work with a GitHub Issues–style workflow | ✅ Create, move between statuses, filter, search, paginate   |
| **Time tracking** | Clock in/out of work sessions                  | ✅ One open session, duration computed on clock-out, history |
| **Automation**    | n8n + Discord surface over the same API        | 🟡 REST API done; Discord bot is a skeleton                  |

## The name

An atom is a fundamental building block of matter — ATOM is a fundamental building block of your digital workflow. The periodic-table inspiration can guide the visual identity: compact element-style tiles, atomic numbers, chemical-symbol typography, and a clean technical interface.

**Brand qualities**

- Minimal and memorable
- Technical, but approachable
- Personal rather than corporate
- Flexible enough to support future features

**Brand idea:** _Your personal workspace, built from the elements of your day._

> Naming note: ATOM is a working name. Check domain, app-store, and trademark availability before public release.

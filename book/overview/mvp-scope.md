# MVP scope

> Chapter 1 — Overview · [Contents](../table-of-contents.md)

From the product spec's MVP section:

## Notes

- Create, view, edit, and delete notes
- Note title and body
- Created and updated timestamps
- Search notes
- Optional tags or simple organization

## Task tracker

- Create, view, edit, and archive/delete tasks
- Task title and description
- Status: **Todo**, **In Progress**, **Done**
- Priority
- Due date, if useful
- Search and filter tasks
- Created and updated timestamps

## Time in / time out

- Clock in and clock out
- Session note
- Date + computed duration per session
- Review list of recent sessions

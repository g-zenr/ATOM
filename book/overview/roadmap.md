# Roadmap

> Chapter 1 — Overview · [Contents](../table-of-contents.md)

Planned (not built yet), from the product spec's "later capabilities" list, in rough priority order:

- Task labels, comments, checklists, attachments (object storage bucket is already declared in `neon.ts`)
- Projects / milestones, Kanban board view
- Links between tasks and notes
- Activity history
- Mobile app (the REST API already exists for it)
- Editing existing notes/tasks (currently create + delete + status moves)

## Where the product spec lives

The full original product thinking — name/brand concept, goals, MVP scope, open questions — is in [`Project Atom.md`](../../Project%20Atom.md) at the repo root. This book is the _engineering_ companion to it.

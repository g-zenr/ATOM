# The dev loop

> Chapter 3 — Quick start · [Contents](../table-of-contents.md)

```bash
npm run dev          # next dev (Turbopack, port 3000)
npm run lint         # ESLint (incl. jsx-a11y)
npm run typecheck    # tsc --noEmit
npm test             # Vitest (shared package)
npm run test:e2e     # Playwright (boots its own dev server)
npm run format       # Prettier
```
